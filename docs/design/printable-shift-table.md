# 印刷用シフト表

設計合意済み（2026-09-05）。

## 目的

`/shifts` から、スクールへの掲示や紙での確認を好む人のためにシフト表を出力する。シフトの確認はシステム上を基本とし、印刷は補助手段とする。

## 決定事項

- 印刷対象の期間は暦月単位とする。
- 12月末から営業を開始するなど、月内の稼働期間が1〜2週間でも月単位で扱う。
- 初期仕様では週単位や任意の期間指定は扱わず、シンプルな月単位の出力を優先する。
- 紙面は日付を縦に並べる一覧型とする。
- 月初から月末までの全日付を載せ、シフトがない日も省略しない。
- シフトがない日にも、現場で急ぎ決めた担当者を手書きできる空欄を残す。
- 印刷対象の部門は「両部門／スキーのみ／スノーボードのみ」の3通りから選ぶ。標準は両部門とする。
- 両部門の場合は、日付の右にスキーとスノーボードの欄を並べる。
- 部門を選べるようにするのは、担当者が3〜5名程度の場合の余白・用紙の無駄を抑えつつ、人数や掲示場所に合わせるため。
- 用紙はA4縦とし、1か月1枚を基本とするが、収まらない場合は複数ページを許容する。年配の利用者もいるため、1枚に収める目的で文字を縮小せず、読みやすさと手書き欄を優先する。同じ日付の内容はページをまたがないようにする。
- シフトの説明文は印刷しない。
- 担当者はシフト種別（一般レッスン／団体レッスン／バッジテスト／県連事業など）の勤務区分で分類する。午前・午後などの時間帯による分類は追加しない。
- 各部門の欄内で「一般レッスン：田中・佐藤」のように種別ごとに担当者をまとめ、種別間で改行する。不要な枠が常に表示されないよう、種別ごとの固定列・固定枠は設けない。
- 担当者がいない勤務枠は種別名も「未割り当て」などの文言も印刷しない。その日の部門内に担当者がいる勤務枠がなければ、完全な空欄として手書きに使えるようにする。
- 紙面に対象年月と出力日時を掲載し、印刷し直した表の新旧を判断できるようにする。
- 操作は `/shifts` の印刷ボタン → モーダルで対象月・部門を選択 → 別タブで印刷用ページを表示 → ブラウザの印刷画面とする。PDF保存もブラウザの印刷機能を利用する。
- プロダクトは印刷対象のデータと印刷用レイアウトを用意する。用紙への収まりや改ページを確認する印刷プレビューはブラウザの機能に任せ、独自のプレビュー機能は設けない。
- 印刷用ページを開いた時点ではブラウザの印刷画面を自動で開かず、ページ内の「印刷」ボタンを押して開く。「印刷」ボタン自体は紙面に掲載しない。
- 対象月の初期値は、印刷ボタンを押した時点で画面内の一番上に見える日付の月とする。モーダルを開いた後は選択月を固定し、ユーザーが変更できるようにする。
- 印刷対象はモーダルで選択した月・部門の全担当者とする。画面の「自分のみ」の絞り込みは引き継がず、印刷用の個人絞り込みも設けない。
- 白黒印刷を前提とし、日付は「5（土）」「21（月・祝）」のように曜日・祝日を文字で識別できる表記とする。罫線・見出しも色の違いに頼らず読み取れるようにする。

## 実装時の確認事項

- 現在も閲覧日付をURLの `date` に反映しているが、日付の検出は IntersectionObserver の通知内で表示割合を比較しており、画面内の最上部の日付と一致する保証はない。月境界で初期月が合意した基準に従うことを確認する。
