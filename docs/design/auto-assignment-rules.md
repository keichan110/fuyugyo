# シフト自動割当の判断ルール

シフト担当者が「自動割当はなぜこの人を選んだのか」を読み解くための文書。2026-11-04 の担当者アンケートと、その後のヒアリングで決めた内容をまとめている。

対象は部門ごとの一般レッスン。例の日付は 2027 年 1 月で、人物はすべて架空。

## ざっくり全体像

自動割当は、次の順番で人を選ぶ。**上の条件は、下の条件で逆転しない。**

| 順番 | 見ること                       | 一言でいうと                                           |
| ---- | ------------------------------ | ------------------------------------------------------ |
| 前提 | 入れない人を外す               | 勤務不可、必要資格なし、同じ日に別の勤務がある人は外す |
| 1    | 必要人数を埋める               | 足りなければ要調整の人も使う                           |
| 2    | 勤務可能な人を優先する         | 要調整の人は、勤務可能な人で足りないときだけ使う       |
| 3    | 4連勤以上を避ける              | 代わりがいなければ4連勤でも入れる                      |
| 4    | シーズンの勤務日数を近づける   | 当該部門の累計が少ない人を優先する                     |
| 5    | 上位ランクのいる枠にする       | 日数が同じときだけ見る                                 |
| 6    | 異なるランクを組ませる         | 日数が同じときだけ見る                                 |
| 7    | それでも同じならランダムに選ぶ | 同じ入力とシードなら同じ結果になる                     |

判断に迷いやすい点は次の3つ。

- **資格より勤務日数が先。** ランクは日数が同じときの判断材料で、上位ランクの人に勤務を集めるためのものではない。
- **要調整は最後の手段。** 累計に大きな差があっても、勤務可能な人を先に使う。
- **認定指導員だけの枠も組む。** ただし「要確認」を付けて、担当者に判断を返す。

## 資格ランク

3つの資格はそれぞれ別のランクで、前にあるほど上位。

| ランク | 資格       |
| ------ | ---------- |
| 1      | 指導員     |
| 2      | 準指導員   |
| 3      | 認定指導員 |

ランクの値は必要資格の設定画面で決まるため、一般レッスンの枠はこの順に設定する。複数の資格を持つ人は、その枠に紐づく資格のうち最上位のランクで判定する。

## 登場人物

スノーボード部門の7人で説明する。シーンごとに、この中の数人と勤務日数を使う。

| 名前 | ランク     |
| ---- | ---------- |
| 青木 | 指導員     |
| 石田 | 指導員     |
| 上田 | 準指導員   |
| 江口 | 準指導員   |
| 小川 | 認定指導員 |
| 加藤 | 認定指導員 |
| 木村 | 認定指導員 |

「累計」は、当該部門のシーズン勤務日数を指す。シーンの日付は、断りがなければ 1月12日（火）。

## シーン別の割当例

### シーン1: ベテランの指導員より、日数の少ない準指導員を入れる

1名の日。出られるのは2人。

| 候補 | ランク   | 累計 | 連絡 |
| ---- | -------- | ---- | ---- |
| 青木 | 指導員   | 18日 | なし |
| 上田 | 準指導員 | 2日  | なし |

**結果: 上田。** 順番4で決まる。1人でレッスンを見る日でも、指導員を優先するルールはない。

### シーン2: 同じ日数なら上位ランクの人を入れる

1名の日。全員の累計が同じ。

| 候補 | ランク     | 累計 | 連絡 |
| ---- | ---------- | ---- | ---- |
| 青木 | 指導員     | 5日  | なし |
| 上田 | 準指導員   | 5日  | なし |
| 小川 | 認定指導員 | 5日  | なし |

**結果: 青木。** 順番4では差が付かず、順番5で最上位ランクの青木になる。

### シーン3: 同じ日数なら異なるランクを組ませる

2名の日。全員の累計が同じ。

| 候補 | ランク     | 累計 | 連絡 |
| ---- | ---------- | ---- | ---- |
| 青木 | 指導員     | 5日  | なし |
| 石田 | 指導員     | 5日  | なし |
| 小川 | 認定指導員 | 5日  | なし |
| 加藤 | 認定指導員 | 5日  | なし |

**結果: 指導員1人と認定指導員1人。** 順番5で指導員が入り、順番6で異なるランクの組み合わせになる。下のランクの人が上のランクの人から学べるように、資格は意図的に混ぜる。

### シーン4: 認定指導員だけになるかどうかの分かれ目

2名の日。認定指導員の小川が先に入っていて、あと1人を選ぶ。

| 上田（準指導員）の累計 | 加藤（認定指導員）の累計 | 結果 | 要確認               |
| ---------------------- | ------------------------ | ---- | -------------------- |
| 20日                   | 2日                      | 加藤 | 認定指導員のみの構成 |
| 6日                    | 5日                      | 加藤 | 認定指導員のみの構成 |
| 5日                    | 5日                      | 上田 | なし                 |

1日差でも勤務日数を優先する。「何日差までなら資格構成を優先する」という基準は、判断が複雑になるので設けていない。

### シーン5: 要調整の人は、日数が少なくても後回しにする

1名の日。上田は「この日は要調整」と連絡している。

| 候補 | ランク     | 累計 | 連絡   |
| ---- | ---------- | ---- | ------ |
| 上田 | 準指導員   | 2日  | 要調整 |
| 小川 | 認定指導員 | 20日 | なし   |

**結果: 小川。要確認「認定指導員のみの構成」。** 順番2で決まる。要調整は勤務が確実ではないので、18日の差があっても勤務可能な小川を選ぶ。

### シーン6: 3人目がいないので要調整の人に頼む

3名の日。出られそうなのは3人だけで、小川は要調整。

| 候補 | ランク     | 累計 | 連絡   |
| ---- | ---------- | ---- | ------ |
| 青木 | 指導員     | 8日  | なし   |
| 上田 | 準指導員   | 8日  | なし   |
| 小川 | 認定指導員 | 8日  | 要調整 |

**結果: 3人とも入れる。要確認「要調整の勤務: 小川」。** 順番1で決まる。担当者は小川に連絡し、出られるかを確認する。

### シーン7: 勤務不可の人は入れず、不足のまま出す

3名の日。青木は「この日は出られません」と連絡している。

| 候補 | ランク     | 累計 | 連絡     |
| ---- | ---------- | ---- | -------- |
| 青木 | 指導員     | 8日  | 勤務不可 |
| 上田 | 準指導員   | 8日  | なし     |
| 小川 | 認定指導員 | 8日  | なし     |

**結果: 上田と小川の2人で「不足 1名」。** 勤務不可の人をとりあえず入れることはしない。不足の理由は「UNAVAILABLE: 1名」と表示される。

### シーン8: 4連勤目だけを避ける

1名の日。上田は直前の勤務があり、江口は前日が休み。

| 上田の直前の勤務               | 上田の累計 | 江口の累計 | 結果 | 理由                    |
| ------------------------------ | ---------- | ---------- | ---- | ----------------------- |
| 1/9・1/10・1/11（今回で4連勤） | 5日        | 20日       | 江口 | 順番3が順番4より強い    |
| 1/10・1/11（今回で3連勤）      | 2日        | 20日       | 上田 | 3連勤までは差を付けない |

候補が上田しかいなければ、4連勤目でも上田を入れる。連勤は禁止条件ではない。

### シーン9: スキーの勤務は日数に数えない

あと1名。上田はスキーでも活動している。

| 候補 | スノーボードの累計 | スキーの累計 |
| ---- | ------------------ | ------------ |
| 上田 | 3日                | 12日         |
| 江口 | 10日               | 0日          |

**結果: 上田。** 勤務日数はスノーボードの枠ではスノーボードだけで比べる。ただし、上田が同じ日にスキーの勤務に入っていれば、前提の条件で外れて江口になる。

## 通し例: 成人の日を含む1週間を組む

1月4日（月）から11日（月・祝）までを自動割当する。人数は平日2名、土日祝3名。祝日の11日も3名で組む。

**開始時点の累計**

| 青木 | 石田 | 上田 | 江口 | 小川 | 加藤 | 木村 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 9日  | 6日  | 8日  | 5日  | 7日  | 4日  | 3日  |

**届いている連絡**

- 青木と上田は、平日の4日〜8日は勤務不可。
- 石田と江口は、5日（火）が勤務不可。
- 上田、江口、加藤、木村は、9日（土）が勤務不可。小川は 9日が要調整。
- 青木、石田、上田、小川、加藤は、10日（日）が勤務不可。

**自動割当の結果**

日ごとに順番に決め切るのではなく、対象の期間全体で評価して入れ替えを繰り返す。そのため、1日だけ見ると累計の最も少ない人が選ばれていないことがある。

| 日付         | 必要 | 割当             | 表示                         | 読み解き                                                      |
| ------------ | ---- | ---------------- | ---------------------------- | ------------------------------------------------------------- |
| 1/4（月）    | 2    | 石田、加藤       |                              | 週全体で累計が揃うように組むので、この日の最少2人とは限らない |
| 1/5（火）    | 2    | 加藤、木村       | 要確認: 認定指導員のみの構成 | 出られるのが認定指導員だけの日                                |
| 1/6（水）    | 2    | 江口、木村       |                              | 勤務可能な人で交互に回す                                      |
| 1/7（木）    | 2    | 石田、加藤       |                              | 勤務可能な人で交互に回す                                      |
| 1/8（金）    | 2    | 江口、木村       |                              | 勤務可能な人で交互に回す                                      |
| 1/9（土）    | 3    | 青木、石田、小川 | 要確認: 要調整の勤務: 小川   | 勤務可能は2人だけなので、3人目を要調整の小川で埋める          |
| 1/10（日）   | 3    | 江口、木村       | 不足 1名                     | 出られるのが2人だけなので、不足のまま出す                     |
| 1/11（月祝） | 3    | 上田、加藤、木村 |                              | 連絡がない日。平日に入れなかった上田が入り、累計を揃える      |

**終了時点の累計**

| 青木 | 石田 | 上田 | 江口 | 小川 | 加藤 | 木村 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 10日 | 9日  | 9日  | 8日  | 8日  | 8日  | 8日  |

開始時点で6日あった最大と最小の差が、2日まで縮まっている。

**担当者がこのあとすること**

1. 1/5 の認定指導員2名で開催してよいかを判断する。
2. 1/9 の小川に連絡し、出られるかを確認する。
3. 1/10 の不足1名をどうするかを判断する。必要人数は目安なので、2名で開催する判断もありうる。

## 要確認の見方

提案に要確認が付くのは次の2つ。ステージへ反映すると勤務枠の備考に「要確認: …」と記録され、保存後も確認できる。

| 表示                 | 意味                                              | 担当者がすること                   |
| -------------------- | ------------------------------------------------- | ---------------------------------- |
| 認定指導員のみの構成 | 枠が認定指導員だけで組まれている（1名の日も含む） | 開催してよいかを判断する           |
| 要調整の勤務: 名前   | 要調整の人が入っている                            | 本人に連絡し、出られるかを確認する |

要確認は、許可済みや出勤確定を意味しない。確認後は備考を編集できる。手動で人を入れ替えても自動では再判定しないので、備考もあわせて更新する。

## 細かい決まり

**申告**

- 連絡がない日は勤務可能として扱う。未登録、アカウント未連携、申告レコードなしで優遇、減点、要確認は付けない。
- 将来の月に連絡がないことは、将来の勤務機会の確約とは解釈しない。

**勤務日数と連勤の数え方**

- 当該部門の全シフト種別を対象に数える。同じ日に複数の枠に入っていても1日と数える。
- シーズン範囲は `seasonRangeForDate` で決める。その範囲の保存済み勤務と、対象月の未保存編集を含める。
- 将来の月に保存済みの勤務があれば含め、未設定の将来の勤務は推測しない。
- 勤務日数は出勤可能日数で補正しない。多く出られると申告した人の割当が増えないようにするためである。
- 月に0日の人を救済する独立したルールは持たない。シーズン累計の平準化で扱う。
- 土日祝と平日に重みの差は付けない。
- 連勤は暦日で連続する勤務を数え、月をまたいでもつなげる。評価値は各連勤の `max(連勤日数 − 3, 0)` の合計で、長い連勤ほど避ける。
- 同日重複の禁止だけは全部門、全シフト種別が対象。

**自動割当の対象日**

- 対象の枠は白紙から置き換えるので、元の勤務は重複判定と勤務日数から除く。
- 対象外の未保存編集は保持し、判断に含める。

**必要人数**

- 必要人数は日別に保存した値を使う。保存した日はその値で割り当て、変更も日ごとにできる。
- 平日2名、土日祝3名は、必要人数が未設定の日の初期値である。画面で変更できる。日本の祝日と振替休日は土日祝の人数を使う。
- 0名の日は開講予定なしとして、自動割当の対象にしない。初期値が0名になる日も同じ。
- 自動割当で初期値を使った日は、その値を未保存の必要人数として補う。人数を変えて再実行すると、この日だけ再計算し、手動で設定した値は保つ。

## アンケートとの違い

アンケートでは「要調整で2日の人」と「勤務可能で20日の人」のどちらを入れるかに、2名とも要調整の人と回答した。その後のヒアリングで、要調整は勤務が確実ではないため、日数の差に関わらず勤務可能な人を優先すると決めた。

同様に「勤務日数の差が何日あれば逆転するか」という重みは使わず、固定の順番にした。判断の説明がしやすく、基準の数値を決めなくて済むためである。

## 探索の限界と検証

- 日付順の初期案を20回作り、最も良い案を、枠内の人の置換と日付間の交換で改善する。改善は最大20,000回の評価で打ち切る。
- 局所探索なので、全体の最適解は保証しない。「別の案を出す」でも、別案が必ずあるとは限らない。
- 実装の入口は `solveAutoAssignments`。本文のシーンと通し例は `test/auto-assign-scenes.test.ts` で実際のソルバーを動かして検証している。ルールを変えるときは、この文書とテストを同時に更新する。
