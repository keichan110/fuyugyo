# レスポンシブな共通ナビゲーション + ロールベースの項目表示を採用する

## Status

accepted

## Context

当初は一般ユーザー（Instructor）の画面が少なく、管理画面も低頻度の操作が中心だったため、ヘッダーのみの構成を採用していた。一方、狭い画面ではヘッダーの導線をドロワーへ集約する必要が生じた。また将来の一般ユーザー向け機能追加に備え、ロールごとにナビゲーション領域そのものを変えるのではなく、共通の領域で項目だけを出し分ける構成が必要になった。

## Decision

Mantine AppShell を使い、画面幅に応じて共通ナビゲーションの表示方法を切り替える。ロールによる制御対象はナビゲーション領域ではなく、各項目とする。

- **デスクトップ**: 開閉可能な左サイドパネルを表示する。ヘッダーにはパネルの開閉、ロゴ、アカウントメニューを配置する
- **モバイル**: ヘッダーのハンバーガーメニューから右ドロワーを開く。アカウント情報・連携解除・ログアウトもドロワー内で直接操作できる
- **共通項目**: ダッシュボード / シフト表
- **MANAGER 以上**: シフト管理 / 資格 / インストラクター
- **ADMIN のみ**: シフト種別設定 / ユーザー / 招待

ナビゲーション定義をサイドパネルとモバイルドロワーで共有する。将来メンバー向けの画面が増えても、共通の定義へ項目を追加するだけで両方に反映される。

## Consequences

- デスクトップではコンテンツ領域がサイドパネル分だけ狭くなるが、ユーザーが開閉できるため、広い編集領域が必要なときは隠せる。
- 新しい画面を追加する場合は、共通ナビゲーション定義へ項目と必要ロールを追加する。
