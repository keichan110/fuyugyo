# シフト割り当て画面の配置方針

対象: #247。2026-11-07 にサンプルで比較し、3領域に分ける方針と、以下のモバイル操作を承認。

## 領域と操作

メニューの「シフト管理」から部門選択の入口へ進み、担当部門を選ぶ。管理画面では勤務種別 → 日付（枠）の順に操作する。

- **カレンダー**: 配置者名を残して当月を俯瞰する。不足・未保存を表示する。名前・人数・備考アイコンを含むセル全体を日付選択に使い、ここでは人を選択しない。
- **編集フォーム**: 選択枠の候補選択・必要人数・備考を扱う。人の分析対象は候補行の「分析」から選ぶ。割り当てチェックとは独立した操作とする。
- **分析**: カレンダーとフォームの下で開閉できる。「月全体」「選択枠」「選択した人」を切り替える。月全体から不足枠へ、人の配置日からその枠へ移れる。

PC（1200px以上）はカレンダーとフォームを左右に並べ、フォーム右上の「×」で閉じると月を広く見渡せる。再表示はカレンダーの日付選択で行い、専用の表示ボタンは置かない。分析はその下に置く。フォームは高さを制限して候補をスクロールできる。

モバイル（768px以下）は **日付リスト → フォーム → 分析を縦積み** にする。画面切り替えや全画面モーダルは使わない。月移動のヘッダーは共有し、日付ごとに配置者名を折り返して表示する。日付行全体で枠を選び、配置人数・必要人数と充足状態、未保存、備考も確認できる。月のリストは高さを制限してスクロールでき、フォームが遠くなりすぎないようにする。768pxを超える狭い画面は月間カレンダーの下にフォーム・分析を並べる。多人数の候補はフォーム内でスクロールでき、備考が候補数に比例して遠くならないようにする。

候補は1行にまとめ、右端に短い「分析」ボタンを置く。選択中は「解除」に変え、カレンダーの強調表示の横からも解除できる。分析領域の開閉は見出し右側の上下矢印で行う。

人を選んだときは、当月の配置日と名前を、PCはカレンダー上、モバイルは日付リスト上で強調する。日別の表示上限で名前が省略された場合も、日付セルの面で配置日が分かる。人の選択は枠を切り替えても保持し、月・部門・種別を変えたら解除する。

## 集計の境界

この画面の俯瞰は、当月の配置の並び（連日・週末への集中）に気づくためのもの。勤務日数の総量を1か月だけで評価しない。

分析「選択した人」の数値（当月・シーズン勤務日数、連勤、連続勤務週数）は、全部門・全種別の勤務を月をまたいで集計する。シーズン（9/1〜8/31）内で打ち切り、未保存の編集を含む。同日に複数枠へ入っていても1日と数える。保存済みの月外分はAPI、当月分は画面の現在案から合成する。対象範囲と期間は数値に併記する。

当月の配置のタイムラインは、表示中の部門・種別を●、同部門の別種別を○、別部門を◆（部門色）、勤務なしを―で描き分け、記号の説明は「記号・集計条件」にまとめ、必要なときだけ表示する。他部門・他種別の勤務は読み上げでも「部門 / 種別」で伝える。

この全部門横断の表示負荷は、自動割当の公平性評価（表示中の部門内の勤務日数）とは範囲が異なる。今回の表示改善で自動割当の方針は変えない。

カレンダー・分析には同じ未保存の配置を渡す。既存の一括保存・編集破棄・画面移動時の確認・自動割当対象日の選択を維持する。

## 保存前の点検（#242）

2026-11-08 の検討で、自動割当の実行前後の履歴は保持せず、保存済みと現在案を比較する方針へ変更した。保存後に確認ステップは追加しない。

- 「月全体」は人数不足・勤務可否（要調整・勤務不可の配置）・4連勤以上・資格構成の件数カードを表示する。件数は対象月・表示部門・種別の枠数で、同じ枠は複数項目に該当しうる。カードで日別一覧を絞り込める。
- 日別一覧に不足人数・対象者・要確認理由を表示し、選ぶと「選択枠」に切り替えて編集フォームへ移動する。同じ要確認事項を選択枠の先頭に表示し、手動修正後も現在案から再計算する。日付を選んでフォームを開くと選択枠へ、閉じると月全体へ連動して切り替える。
- 連勤は自動割当の評価に合わせ、同部門・全種別・シーズン内の月外勤務を含む。「選択した人」の全部門横断の負荷表示とは対象範囲が異なる。既存コンテキストに月外勤務がない配置者は、連勤未判定として表示する。
- 必要人数・資格の未設定や取得失敗は、問題なしと区別する。必要人数の未設定件数は人数不足カード内に表示し、その他の未判定・一部未判定もカードに明示する。
- 保存済みとの差分は、カレンダー上部の「差分」から開くモーダルへ集約する。対象は担当部門・当月・表示中の種別で、担当者の追加・解除、必要人数、備考の変更を枠ごとに比較する。並び替えや元に戻した値は差分としない。分析パネルから保存済みとの比較や変更バッジを除く。差分用の履歴Stateは持たず、保存済みと現在案から導出する。
- 自動割当時に備考へ書かれた要確認は実行時の記録のまま。分析の現在案の判定とは分け、手動編集後も備考を自動では書き換えない。

## 充足率と分析の可視化（#241）

- 月全体の不足分布はカレンダーとモバイルの日付リストの背景で表す。必要人数が正の枠は配置人数÷必要人数の充足率を用い、不足率が高いほどオレンジを濃くする。100%は通常背景、過員は注意色の黄〜琥珀を超過率に応じて濃くする。必要人数未設定と0人・配置なしは白（ダークモードでは通常背景）。必要0人で配置ありは比率を定義せず、過員の青を使う。
- 公開済みは薄い緑の1px内側枠線、選択中は青の内側枠線を使う。背景の充足率は選択中も残す。選択中の枠線が公開枠線に優先する。個人の配置日は点線と名前の強調で示す。
- 前後月の日付セルはグレーで表示し、通常操作では押下・キーボード操作で日付選択を解除してフォームを閉じ、分析を月全体へ戻す。未保存の変更と分析中の人は保持する。自動割当中は対象月外を選べない。
- 選択枠は充足率のリングを表示し、100%を超える値も数値に残す。資格ランク別の配置人数は横棒で比較する。ランクごとの必要人数は定義されていないため、必要人数の棒は作らない。担当者名は上部の担当者一覧にまとめ、グラフ直下のランク別の人数・氏名テキストは重複するため表示しない。資格要件外の氏名と確認理由は残す。
- 個人分析は月曜始まりの週別勤務日数を、「表示中の部門・種別」「同部門の別種別」「別部門」の3本の棒で比較する。週別グラフの凡例にタイムライン用の記号は付けない。同部門の別種別は薄緑。各分類で同日複数配置は1日だが、同日が複数分類に該当する場合があるため棒は単純合算しない。月境界の週は当月分のみ。連勤・連続勤務週数の既存指標は引き続き月外を含める。
- 個人の日別タイムラインは同日の複数勤務をすべて記号で示し、代表記号による省略をやめる。グラフ・タイムラインも未保存の現在案を使う。

- 分析の数値・グラフ・タイムラインはすべて現在案に統一し、仮配置による見込みや保存済みとの比較を表示しない。人の勤務量は当月・シーズン・連勤・連続勤務週数の4カードとする。日付未選択では連勤・週数の代わりに日付選択を促す。選択日に実際の勤務がなければ連勤なし、選択週に勤務がなければ連続勤務週なし。別部門の実際の勤務も含め、仮の勤務日を加えない。

- 月全体は横軸を当月勤務日数、縦軸を人数とするヒストグラムで分布を表示する。対象は表示枠の資格を持つ候補者と現在案の配置者の和集合。全部門・全種別の勤務を同日1日で集計し、1人を1つの階級にだけ含める。0日と途中の人数0の階級も表示する。中央値は0日も含む対象者全員から計算し、偶数人数では中央2値の平均（0.5日刻み）を表示する。数値軸上の破線で中央値を示す。対象者なしと全員0日を区別する。
- ヒストグラムの棒から直接該当者を表示する。勤務日数の選択欄は置かず、人名の横の小さな「分析」ボタンから既存の個人分析へ進む。未保存の編集も反映する。部門・種別の内訳は個人分析で扱う。勤務可能日数や希望日数を加味した公平性の判定は行わない。

- 分析タブは月全体を常時表示し、枠・人のタブはそれぞれ選択がある場合のみ表示する。枠のタブ名は選択日の日付、人のタブ名は選択者の氏名とする。選択解除後は該当タブとパネルを非表示にする。

- 分析パネルの上部に対象変更・解除操作を置く。日付は当月の日付選択と前日／翌日ボタン（当月の端では無効）で切り替えられる。ここからの変更ではフォームへスクロールせず、現在の分析位置を保つ。日付解除はフォームを閉じ、選択中の人がいれば個人分析、いなければ月全体へ戻る。人は検索付き選択欄で候補者・当月配置者から切り替えられる。未保存変更は保持し、自動割当中は変更・解除を無効にする。

- カレンダーの配置者名の右に勤務可否アイコンを表示する。勤務可は控えめなグレーのチェック、要調整は黄色の警告、勤務不可は赤の×、未入力は点線の丸とする。読込中・取得失敗は未入力と区別する。モバイルの日付一覧にも同じアイコンを使う。名前が省略される場合もアイコンは残し、セル全体から日付を選択できる既存操作を維持する。日付セルのホバー説明に申告状態・コメントを含める。

- 勤務種別はセレクトで変更し、表示中の種別に実際の変更がある場合だけ「差分」ボタンを表示する。ボタンに枠数は付けず、モーダル内も種別名・枠数の表示を省き、日付ごとの変更だけを示す。

## 最終UX調整

- 人の分析中も、他の人の勤務可否アイコンは薄くしない。対象外の人名だけを控えめにし、警告の視認性を維持する。候補の資格バッジは部門色ではなく中立色にする。
- フォームの「分析」を押したときは分析パネルを開き、見出しへスクロール・フォーカスする。人の分析中にカレンダー・タイムラインから日付を選んでも、人のタブと現在のスクロール位置を維持する。フォームを閉じても人の分析を維持する。月全体の問題日から編集へ進む場合は従来どおりフォームへ移動する。
- カレンダー上部の長いサマリーは月全体分析へ移す。必要人数未設定・開講なし・不足・充足・過員を重複なく集計し、構成比バーと日数で表示する。カレンダーの表示説明は「表示の見方」の色見本・アイコンに集約し、長い凡例を常設しない。
- 月全体の確認日一覧は初期状態で閉じ、件数カードを押すと絞り込んだ一覧を開く。未設定などの判定不十分な状態だけでは件数カードを警告色で塗りつぶさない。集計条件は折りたたみ内にまとめる。
- 勤務不可の候補は初期状態で閉じる。ただし検索中や、勤務不可の人がその枠に配置済みの場合は開き、解除できるようにする。
- 週別グラフは短い月日表記で全週のラベルを出し、狭い画面では横スクロールで読める幅を確保する。長い集計条件やタイムラインの記号説明は初期状態で閉じる。

- 「表示の見方」はカレンダーの月移動・今日と同じ行の右端に固定し、差分の有無で移動しない。「差分」は上部ツールバー右側の操作群に配置する。
- フォームの「配置済み」も初期状態で閉じる。検索で該当する人を探す場合は開く。
- 当月の必要人数が全日未設定の場合は「未判定」とし、0日の状態を並べず未設定の日数だけを表示する。必要人数未設定を配置人数から推測して補完しない。

- 過員はカレンダー背景・選択枠のリング・月全体の構成比で黄〜琥珀色に統一し、良好に見える青を使わない。人数表示でも「過員」として区別し、充足の緑チェックではなく注意アイコンを示す。

## 部門の入口と勤務種別

- メニュー構成は変更しない。「シフト管理」から `/shifts/manage` を部門指定なしで開くと、スキー／スノーボードの2つのカードを中央に置いた選択画面を表示する。部門未選択では編集用コントローラーやデータ取得を開始しない。
- 選択した部門は `department` 検索パラメータに保持する。再読み込み・部門指定の直接リンクでは同じ部門を復元する。不正な指定では既定部門を開かず、入口へ戻す。以前のローカルストレージの部門選択は使用しない。
- 管理画面の見出しは「スキーのシフト管理」など部門名を固定表示する。画面内に部門切り替えは置かない。部門を選び直す場合はメニューの「シフト管理」を選択し、部門指定を外して入口へ戻る。
- 勤務種別はカレンダーパネルの外、画面見出しの右側に置いたセレクトで変更する。画面全体の編集対象を切り替える操作として扱い、未保存の変更がある種別切り替えでは既存の破棄確認を維持する。メニューから入口への移動やブラウザー履歴での部門変更でも、画面遷移のブロッカーで未保存変更を保護する。
- 個人の勤務量は引き続き全部門・全種別で集計し、入口で選択した部門だけに限定しない。

- 月移動ヘッダーは Mantine ScheduleHeader で組み立て、前月・月年選択・翌月・今日・右寄せの表示の見方を1行に配置する。モバイルでは表示の見方を情報アイコンにし、アクセシブルな名前は維持する。月移動・月年選択は既存の未保存変更確認を通す。

- 勤務日数分布の棒はキーボードでも選択できる。人数がある棒にTabでフォーカスし、Enter／Spaceで該当メンバーを表示する。日数・人数と選択状態を読み上げ、無効時や0人の棒はタブ移動の対象外にする。
